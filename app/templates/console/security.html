{% if emergency %}on{% else %}off{% endif %}

One switch that stops the app using anyone's Microsoft access: no scans, no new connections, no one-click fixes and no Azure cost reads. People can still sign in and read the reports already here; customers see “paused for maintenance”.

Check these yourself

  • MFA on every key accountYour Microsoft admin, GitHub and Azure accounts, ideally passkeys or the Authenticator app.
  • App instance property lockEntra → App registrations → your app → Authentication: on, so no one can add a secret to your app inside a customer's tenant.
  • Backups off the serverAzure Backup on the VM, or copies of deploy/backups somewhere else.
  • Cloudflare in frontA Cloudflare Tunnel hides the server and blocks floods (docs/DEPLOY_SERVER.md).
  • Private vulnerability reportingGitHub → repository Settings → Code security: on, so people can report problems privately (SECURITY.md).
