1. Register the app in Microsoft Entra

  1. In your own Tenvaultix tenant, open Microsoft Entra admin center > App registrations > New registration.
  2. Name: Tenvaultix 365 Health Check. Supported account types: Accounts in any organizational directory (multitenant).
  3. Redirect URIs (type Web):
    • {{ settings.url('/auth/callback') }}
    • {{ settings.url('/connect/callback') }}
  4. Under Certificates & secrets, upload a certificate (recommended) or create a client secret.
  5. Under API permissions, add the delegated permission User.Read and these application permissions for Microsoft Graph:
{% for name, why in permissions %}{% endfor %}
{{ name }}{{ why }}
  1. Under Branding & properties, set the publisher domain, then complete publisher verification with your Microsoft partner account, so customers see a verified badge instead of "unverified".

2. Set environment variables

TVX_CLIENT_IDApplication (client) ID
TVX_CERT_PATH + TVX_CERT_THUMBPRINTPrivate key file and certificate thumbprint (or TVX_CLIENT_SECRET)
TVX_BASE_URLPublic address of this site, for example https://health.example.com
TVX_SESSION_SECRETLong random string used to sign session cookies
TVX_CONTACT_EMAIL / TVX_BOOKING_URLWhere "Ask Tenvaultix to fix this" buttons go
